🔑 Key Architecture & Features
Bring Your Own Key (BYOK): Connect directly to your preferred AI providers (OpenAI, Anthropic, Gemini). API keys are encrypted locally using AES-256-GCM via the native OS credential manager and never touch third-party servers.

Native OS Perception: Combines high-speed screenshot vision parsing with Windows UI Automation (UIA) tree hooks for pinpoint coordinate accuracy and sub-20ms element targeting.

Cross-Application Workflows: Seamlessly navigates between web browsers, code editors (VS Code), spreadsheets, terminals, and local file managers while maintaining persistent execution context.

Self-Healing Execution Loops: Built-in error-recovery heuristics detect UI discrepancies or unexpected app popups, dynamically recalculating alternative execution paths.
